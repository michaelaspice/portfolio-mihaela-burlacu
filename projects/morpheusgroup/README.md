# MorpheusGroup — Customer Health & Churn Analysis

This folder is designed to live inside:

`portfolio-mihaela-burlacu/projects/morpheusgroup/`

The case study page is available at:

`projects/morpheusgroup/index.html`

## Files

- `index.html` — public portfolio case-study page
- `analysis.sql` — cleaned SQL queries
- `findings.md` — concise findings
- `project-card.html` — card snippet for the main portfolio homepage

## Important

Add the **original synthetic CSV that you actually analyzed** to this folder if you want the dataset to be public.

Recommended filename:

`morpheusgroup_customer_data.csv`

Do not replace it with a newly generated dataset, because the published findings should match the underlying data.
