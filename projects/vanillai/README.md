# Elix.ai — Revenue Operations Funnel & ICP Analysis

Synthetic B2B SaaS Revenue Operations case study using SQL to identify funnel performance, revenue-efficient segments, and a target ICP.

## Target ICP
- SaaS & Fintech
- 501+ employees
- DACH, Nordics, Benelux

## Key result
The identified ICP represented only 4% of leads but generated about 18% of won ARR, achieved a 20.0% lead-to-win rate, and produced more than 5× the ARR per lead of other segments.
